I used Claude AI extensively while developing VangtiChai, an offline Android application for calculating Bangladeshi Taka denominations. I provided Claude AI with a detailed development prompt describing the app's requirements, functionality, user interface, calculator logic, and testing requirements.

Claude AI assisted me in the following areas:

- Project Setup and Development: Generated and assisted with the Android Studio project structure, Gradle configuration, Kotlin source code, XML layouts, resources, and required dependencies using Kotlin and XML, with a minimum SDK version of 24.

- User Interface Design: Helped create a modern blue-and-white interface with a custom app logo, a large amount display featuring the ৳ symbol, eight currency denomination cards, a custom numeric keypad, rounded buttons, and the "Made By AB" footer.

- Calculator Logic:** Assisted in implementing the greedy algorithm to calculate the required quantities of Bangladeshi Taka denominations (৳500, ৳100, ৳50, ৳20, ৳10, ৳5, ৳2, and ৳1) using division and the modulus operator.

- Keypad Functionality: Helped implement numeric input from 0 to 9, the CLEAR button, backspace functionality, a maximum input length of nine digits, and validation to prevent negative values, decimal inputs, and unnecessary leading zeros.

- Responsive Layouts and Screen Rotation:** Assisted in creating separate portrait and landscape XML layouts and responsive resources for tablets, including `values-sw600dp`. I also used AI assistance to understand activity lifecycle management and preserve the entered amount during screen rotation.

- Debugging and Problem Solving: Used Claude AI to identify and resolve development issues, including keypad layout problems on tablet screens and lost inputs during rapid, repeated button presses.

- Testing and Verification: Used AI assistance to write and review unit tests and UI tests, including Espresso tests, and to check calculator accuracy for zero, small amounts, large amounts, and the maximum nine-digit input. I also checked CLEAR and backspace functionality, repeated button presses, screen rotation, and layout behavior on different screen sizes.
