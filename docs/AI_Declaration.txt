3. DESCRIPTION OF AI USE
------------------------------------------------------------
I used Claude AI extensively while building VangtiChai, an
Android application that calculates Bangladeshi Taka
denominations.

Claude generated most of the project from the requirements
in the assignment PDF, including the Android Studio/Gradle
project setup, the Kotlin source files, the XML layouts and
resources, and the unit and UI tests. I gave the
requirements, asked for changes and improvements, and
reviewed the results.

I also used AI assistance to:
- understand Kotlin and Android concepts (activity
  lifecycle, saving state on rotation, ConstraintLayout,
  resource qualifiers for phones and tablets)
- find and fix problems, such as the keypad not fitting on
  7-inch tablet screens and quick repeated key taps being
  lost
- write and run unit tests, UI (Espresso) tests and
  emulator checks on Pixel XL and Nexus 10
- write the README.txt documentation and notes that explain
  the code
- prepare Google Play release materials: privacy policy,
  store listing text, the feature graphic (made from my own
  app logo) and app screenshots. The app logo itself was
  provided by me.

I reviewed the generated code, studied how it works and
tested the application during development.
